# Advanced Portfolio Platform

A production-style full-stack developer portfolio platform.

## Tech Stack

- Frontend: Next.js, Tailwind CSS
- Backend: FastAPI
- Database: PostgreSQL
- Auth: JWT
- Testing: PyTest
- Deployment: Vercel, Render, Neon

## Modules

- Public Portfolio Website
- Admin Dashboard
- Backend APIs
- Database Integration
- Authentication
- Testing
- Deployment
